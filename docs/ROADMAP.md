# Portfolio Roadmap

## 완료된 MVP

- 반응형 아침 브리핑 대시보드
- 시장·포트폴리오·오늘의 포커스 API 렌더링
- SQLite/PostgreSQL 호환 사용자·종목·관심종목 모델
- 관심종목 추가·조회·삭제와 중복/미지원 종목 오류 처리
- Mock/Gemini 교체형 공개 뉴스 구조화 분석
- Celery/Redis 아침 배치 기반, Alembic 마이그레이션, Docker Compose, CI
- API 및 CRUD 자동 테스트

## 포트폴리오 2차 목표

- 미국 시세·뉴스 공급자와 국내 시세 공급자 연결
- KOSPI/KOSDAQ 종목 검색 및 관심 종목 지원
- 수집 기사 중복 제거 및 관심 종목 관련성 점수 저장
- 브리핑 생성 이력과 상세 페이지
- 소셜 로그인 및 사용자별 데이터 격리 테스트
- 공개 데모 배포와 시스템 설계·트러블슈팅 기록

## 제외 범위

- 매수·매도 주문
- 수익률 보장 또는 방향 예측
- 토스증권 비공개 API 우회 연동
